How this dashboard works
  • Local files refresh every 3 seconds. Building, submitting, packaging, and publishing happen through the CLI, not this page.
  • Apple acceptance is only one step. Share only the verified distribution ZIP, not the submission ZIP.
  • “Refresh Apple” makes a read-only query using Keychain credentials. It never uploads or changes a run.
  • “Reveal ZIP in Finder” checks the checksum before opening Finder on this Mac. If copying fails, copy the path from Technical details.
  • itch.io status comes from local receipts. Use the CLI for a remote channel check; this page never accesses publishing credentials or uploads.
  • A successful itch upload is not a verified delivery. Download and playtest on another Mac before broader distribution.
